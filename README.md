# Student Performance Analytics

## Project Overview
This project analyzes student performance using Python and Pandas.

## Dataset
- Source: Kaggle
- Records: 1000 students
- Features: Gender, race/ethnicity, parental education, lunch type, test preparation course, math score, reading score, writing score.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Key Findings
- No missing values or duplicate records.
- Reading had the highest average score.
- Students who completed the test preparation course generally performed better.
- Reading and writing scores showed a strong positive correlation.
